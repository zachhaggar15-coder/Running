Planning a first half marathon

For a first half, start with the time limit, arrival plan and on-course support. These records expose different trade-offs: a closed-road city race, an undulating country route, a trail option and a lap-based venue.

A published cut-off is not a pacing guarantee. Check the organiser's current race-day instructions and choose the exact distance before making travel plans.
