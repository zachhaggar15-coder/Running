# Race Fieldnotes site

The static site contains 400 source-linked UK race and run-challenge profiles, a searchable directory, six decision guides and a sitemap. Race records live in `data/races.json` and the `data/race-expansion*.json` files; individually reviewed updates to older records live in `data/verified-updates.json`. `scripts/rebuild-profiles.js` regenerates the profile HTML, catalogue data, directory and sitemap.

Missing race facts remain labelled as unconfirmed. Organiser pages are linked for entry and final race-day instructions. The illustrations are original editorial artwork, not official course photographs.
