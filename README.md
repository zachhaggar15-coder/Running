# UK running race discovery platform

This repository holds the research and, after the owner's checkpoints, the implementation of an independent UK running race directory. It is **not a launched website**.

The starting brief calls for researched, source-linked profiles of road, trail and ultra events across the four UK nations, useful discovery and comparison, and low-maintenance updates. It explicitly requires Stage A feasibility review before substantial implementation and separate approval for public deployment.

## Current checkpoint

- [Stage A: research and feasibility](docs/STAGE_A_FEASIBILITY.md)
- [Source compliance register](docs/SOURCE_COMPLIANCE_REGISTER.md)
- [Project status and decisions](PROJECT_STATUS.md)

No race records, importer, production infrastructure or public site have been created. The 200–300 profile target remains unproven and conditional on quality and lawful sourcing.
